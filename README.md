# Matchup-League-2

Detailed info for developers can be found in manual.md

Matchup League is a card game, in which every single card is unique. This project is just a small slice of the
expansive teams, leagues, and history that has gone into making Matchup League what it is.

The game was originally played on paper, first created in 2015. The very first league was called Palette League, and featured
teams named after colors. Season after season, the league grew, multiple tiers of leagues were introduced, and extra mechanics
to make the game more interesting were added. Now, after ten years and 29 finished seasons, Matchup League is finally going digital.

This project only features the season 29 Prep League teams. The teams and cards are based on an assortment of fictional and made-up series. The end goal of the project is to make 29 Prep League the very first official Matchup League season conducted entirely digitally.
